
#### Catchup

Catchup by default is FALSE.

- False - will not trigger dags for interval from start_date to now()
- True - will trigger dags for internval from start_date to now();

#### Options to setup schedule

- CronTriggerTimetable - python class CronTriggerTimetable("@daily", timezone="UTC")
- Cron expression
	- 0 0 * * MON,WED,FRI—Run every Monday, Wednesday, and Friday at midnight
	- 0 0 * * MON-FRI—Run every weekday at midnight
	- 0 0,12 * * * —Run every day at 00:00 and 12:00
