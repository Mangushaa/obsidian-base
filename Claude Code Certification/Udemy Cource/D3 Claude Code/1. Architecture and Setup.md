# Adding and Managing Context Effectively


#### Compaction

When context fills, older turns get summarized so the session can keep going.

- Auto-compaction triggers automatically as the context windows approaches it's limit
- The /compact command runs the same summarization on demand before you hit limit
- A CLAUDE.md compact instruction tells the summary what details to always preserve
- Compaction trades verbatim history for a summary that keeps session alive


# Permission Modes

- Permission mode - a session wide setting that decides which actions run without asking and which still prompt you

#### Modes

- default - reads run freely. Edits and commands prompt you every time. Best for sensitive or first-time work
- acceptEdits - auto approved edits and common file commands in your working directory. Good for iterating on code
- plan - reads and explores only. Proposes changes without touching your source. Good before you commit for edits.
- dontAsk - auto denies anything you have not pre-approved. Only allow-listed tools and read-only commands run. Fully not-interactive.
- bypassPermissions??? - skips prompts entirely so tool calls run immediatly. Powerful but risky. Reserve it for isolated containers or virtual machines where nothing can be damaged.
