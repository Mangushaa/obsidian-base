
**Agentic System** - LLM achieve a goal by selecting actions invoking tools, and iterating until goal is reached

**Workflow** - fixed sequence of steps defined by developer that runs predictably

**Autonomous Agent** - reach goal without humen intervention making it's own decision


**Augmented LLM** - LLM enhanced with memory, retrieval and tools.


**Retrieval and Tools** - model generate it's own queries and choose correct tool to satisfy it.

**Memory** - model persists needed information between diffirent steps and calls (e.g Context)
