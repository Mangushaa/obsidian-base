
As you send your logs to Datadog, you’ll want to make sure that pipeline filters match incoming logs, and that pipelines are properly processing the logs. You can use the [Pipeline Scanner](https://docs.datadoghq.com/logs/log_configuration/pipeline_scanner/) to troubleshoot and manage how logs are processed by your log pipelines in near real time.

In individual pipelines, you can add a Remapper processor to remap the name of an attribute to the standard name for that attribute.

However, if you have logs from different sources with the same attribute and you want to make sure that the attribute has the same name across all logs, you can use a **Standard Attribute**. A Standard Attribute acts as a global remapper for the attribute and is applied to all logs after the pipeline processing stage.
