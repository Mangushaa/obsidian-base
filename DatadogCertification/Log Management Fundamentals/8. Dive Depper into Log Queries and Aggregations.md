
# Querying Logs for Insights

This course will cover using Log Explorer for the following:

- Visualizing analytics for “count unique of” and statistical operations for log attributes using Fields aggregations
- Building multiple queries and formulas
- Transforming queried data in visualizations using functions
- Aliasing facets to remap non-standard attribute names to standard attribute names
- Aggregating logs with similar message formats or attribute values using Patterns
- Aggregating logs for a sequence of related events that share a tag or attribute value using Transactions

![[SfKTFQwRQgAbY8qwTqTk_02-logsearchsyntax_labdataschema 1.pdf]]


To build queries with tags and attributes, you don't need to convert them to facets and measures. However, doing so makes it easier to understand, navigate, and interact with this data in Log Explorer. For example, you'll be able to use the autocomplete feature in the search field.
