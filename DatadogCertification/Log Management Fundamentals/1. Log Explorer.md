#  Facets and Measures

Your logs contain thousands of unique attributes that change over time. You can create [facets and measures](https://docs.datadoghq.com/logs/explorer/facets/) from tags and attributes in your indexed logs. Facets/measures appear in the facet list on the left side of Log Explorer

You can add a facet or measure for a tag or attribute from the log details. When you click a tag or attribute in the log details, a menu will appear. If the value is a string, you’ll only have the option to create a facet. If the value is a number, you’ll have the option to create a facet or measure, as shown in the example below.

# Fields Aggregations

In Log Explorer, you’ll find three options for “Group into” [aggregations](https://docs.datadoghq.com/logs/explorer/analytics/):

- Fields - Logs matching your search query are aggregated into groups to displayed in visualizations as counts and/or statistics.
- Patterns - Logs that have similar formats are listed in groups.
- Transactions - Logs are grouped according to instances of a sequence of events, such as a user session or a request processed across multiple microservices. For example, all the log events related to a user session will be grouped together and each grouping will be listed as a transaction.

There are six different visualizations in Log Explorer.

[Timeseries](https://docs.datadoghq.com/logs/explorer/visualize/#timeseries) - Graph of the counts of logs or statistics for a single measure over a selected time frame based on the search query. You can optionally split by up to three available facets.

#  Saved Views

Saved view allow to save currenf search query, grouping with chart, and time tracker under certain name so you can open it whenever you need in saved view menu by name. After making some changes you can update view by clicking saving the changes. Basically view making snapshot of your current search setup including columns, facets, etc. So when you change it later, you always can rollback to it.

 A Saved View keeps track of the following:

- The search query along with its time range.
- The visualization along with their specific visualization properties
- The selected subset of facets to be displayed in the facet list.

Note that a saved view is meant to track live time ranges (such as past hour, or past week) only. If you save a view for a fixed time range, the saved view will save the time range as the equivalent live time range. For example, you can save a query for a fixed time range of `July 21, 2024 to July 25, 2024`. When you open the saved view, the time range will be `Past 5 days`.

# Summary 

Datadog provides a friendly interface for you to query and analyze logs for your log observability workflows. Log Explorer is your home base for log troubleshooting and exploration of your indexed logs. You can use Live Tail to view and search all of your ingested logs. In both, you can query logs using search syntax and facets that match specific details that are found in your logs. This allows you to quickly comb through all of your logs from all of your sources to find the specific subset of logs you’re looking for. With Fields aggregations, you can visualize counts of logs based on any search query, group by selection, and selected time range. This allows you to analyze your logs for insights about your infrastructure and applications.
