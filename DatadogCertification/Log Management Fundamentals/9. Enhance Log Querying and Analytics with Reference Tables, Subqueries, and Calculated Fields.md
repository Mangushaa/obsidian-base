In the [Getting Started with Log Explorer](https://learn.datadoghq.com/courses/log-explorer) course and the [Dive Deeper into Log Queries and Aggregations](https://learn.datadoghq.com/courses/log-queries-aggregations) course, you learned how to query and aggregate logs using tags, attributes, and text in log messages.

As you build queries and visualizations in Log Explorer, you’ll often come across use cases that require you to enhance your queries in one of the following ways:

- Import and combine reference metadata with data in logs to gain deeper insights
- Query one set of logs using matching tags, attributes, and text in another set of logs
- Use tag or attribute values in certain logs to calculate values for a new field for those logs

Datadog Log Explorer provides a solution for each of these use cases.

You can upload data tables into [Reference Tables](https://docs.datadoghq.com/logs/explorer/advanced_search#filter-logs-based-on-reference-tables) and then join these tables with logs in Log Explorer.

![Example of a reference table join. Data in the reference table is used to search for logs with related data.](https://learning-assets.datadoghq.com/enhance-log-querying/lms/assets/referencetables-intro.png)

Example of a reference table join. Data in the reference table is used to search for logs with related data.

You can use [Subqueries](https://docs.datadoghq.com/logs/explorer/advanced_search#filter-logs-with-subqueries) to query one set of logs using a tag or attribute in another set of logs.

![Example of a subquery. Data in one set of logs is used to search for data in another set of logs.](https://learning-assets.datadoghq.com/enhance-log-querying/lms/assets/subqueries-intro.png)

Example of a subquery. Data in one set of logs is used to search for data in another set of logs.

You can use [Calculated Fields](https://docs.datadoghq.com/logs/explorer/calculated_fields/) to create a new field using values from other tags and attributes.

![Example of a calculated field. New data is created in logs using data that exists in those logs.](https://learning-assets.datadoghq.com/enhance-log-querying/lms/assets/calculatedfields-intro.png)

Example of a calculated field. New data is created in logs using data that exists in those logs.

After performing these tasks, you can add another query, write formulas, or build visualizations with these enhanced queries and new fields.
