# Moderation model API

OpenAI has the ability to moderate a prompt containing potentially harmful or sensitive idx_4994310a content sent by a user. When the response is generated by an AI model from the user's prompt, the content can be intercepted on return, evaluated, and handled appropriately. If harmful or sensitive content is detected, the content generated in response to the user's inappropriate prompt can be blocked or filtered

```
@Bean
ApplicationRunner programRunner(OpenAiModerationModel model) {
    return args -> {
        String text = "How to launder money?";
        ModerationPrompt prompt = new ModerationPrompt(text);
        print("prompt> %s", prompt.getInstructions().getText());
        ModerationResponse response = model.call(prompt);
        Moderation moderation = response.getResult().getOutput();
        for (ModerationResult result : moderation.getResults()) {
            print("Flagged: %s", result.isFlagged());
            Categories categories = result.getCategories();
            print("Dangerous and Criminal Content: %s",
                    categories.isDangerousAndCriminalContent());
            print("Financial: %s", categories.isFinancial());
            print("Law: %s", categories.isLaw());
            CategoryScores scores = result.getCategoryScores();
            print("Dangerous and Criminal Content Score: %s",
                    scores.getDangerousAndCriminalContent());
            print("Financial Score: %s", scores.getFinancial());
            print("Law Score: %s", scores.getLaw());
        }
    };
}
```


# Embeddings model API

A key component in Spring AI's Embeddings Model API is the EmbeddingModel interface. The model accepts an EmbeddingRequest containing the content used to generate the Embeddings, which are returned in an EmbeddingResponse

```
@Bean
ApplicationRunner programRunner(EmbeddingModel embeddingModel) {
    return args -> {
        String text = "To be, or not to be, that is the question.";
        float[] vector = embeddingModel.embed(text);
        System.out.printf("prompt> %s%n", text);
        System.out.printf("Vector Dimension: %d%n", vector.length);
    };
}
```

# Image model API

The primary interfaces and classes in Spring AI's Image Model API are the ImageModel, ImagePrompt containing ImageMessages along with ImageOptions, and ImageResponse containing ImageGenerations.

```
@Bean
ApplicationRunner programRunner(ImageModel imageModel) {
    return args -> {
        String instructions = """
                Generate an image of an upside down cat suspended in
                midair, parallel to the ground, with a slice of
                buttered bread directly on the cat's back.
                """;
        OpenAiImageOptions opts = new OpenAiImageOptions();
        opts.setWidth(WIDTH);
        opts.setHeight(HEIGHT);
        opts.setSize(IMAGE_SIZE);
        ImagePrompt prompt = new ImagePrompt(instructions, opts);
        ImageResponse response = imageModel.call(prompt);
        ImageGeneration imageGeneration = response.getResult();
        Image image = imageGeneration.getOutput();
        String URL = image.getUrl();
        System.out.printf("URL [%s]%n", URL);
        System.out.printf("Image Base64 JSON [%s]%n", 
                image.getB64Json());
    };
}
```

# Prompt engeneering

Effective technique to get what you want is to provide an example. This technique is applied by Spring AI's StructuredOutputConverters, which augment the prompt with instructions.

Out of the box, Spring AI provides three converters to structure the generated response returned by an AI model. We have the ListOutputConverter, MapOutputConverter and BeanOutputConverter.

```
import java.time.ZonedDateTime;
import java.time.format.DateTimeFormatter;
import java.time.temporal.TemporalAccessor;
import org.springframework.ai.converter.StructuredOutputConverter;

public class Rfc1123DateTimeStructuredOutputConverter implements StructuredOutputConverter<ZonedDateTime> {

    public static final Rfc1123DateTimeStructuredOutputConverter INSTANCE = new Rfc1123DateTimeStructuredOutputConverter();

    @Override
    public String getFormat() {
        return "Respond only with the date and time in RFC 1123 format.";
    }

    @Override
    public ZonedDateTime convert(String source) {
        // .trim() helps clean up extra spaces or newlines returned by the model
        TemporalAccessor dateTime = DateTimeFormatter.RFC_1123_DATE_TIME.parse(source.trim());
        return ZonedDateTime.from(dateTime);
    }
}
```


# Handling documents

Spring AI provides a comprehensive and robust API for working with documents, such as PDF, DOCX, Plaintext, JSON, HTML, Markdown, along with several other document types. The core component in the API is the Document interface

Understanding idx_8cb49eb1 and ingesting different types of documents is the responsibility of Spring AI's DocumentReader interface. Once ingested, documents can be supplied to DocumentTransformers for additional processing and transformation that makes the contents of these documents easier to interpret by an AI model. Finally, the DocumentWriter can consume the transformed documents for storage and retrieval when necessary.
